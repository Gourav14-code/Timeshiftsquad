# TIME SHIFT SQUAD

A 3D Action RPG & Runner game built with JavaScript, Three.js, HTML5, and CSS.

## Features
- **Exploration & Encounter State Machine**: Seamless transitions from exploration to locked combat arenas.
- **Dynamic 3D Path with Connected Y-Junction**: Walkable curves, branches, and scenery.
- **Active Combat System**: Melee sword slashes, bow arrows, and sci-fi blasters with hit-stop, knockback, and floating damage numbers.
- **Squad Recruitment**: Rescue friendly heroes along the route who join your squad and actively fight alongside you.
- **Time Shift Portals**: Circular clock machine portals that upgrade your hero's era, weapons, and stats.
- **Mobile & Desktop Controls**: On-screen touch analog joystick and responsive WASD keyboard controls.

## How to Play
Run a local static HTTP server:
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
